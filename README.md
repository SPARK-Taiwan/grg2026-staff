# GRG 2026 工作人員專區

網站（GitHub Pages）＋後台（Google 試算表＋Apps Script）。電話只存在試算表裡，不會出現在網站上。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html`、`style.css`、`app.js` | 網頁 |
| `roles.js` | 20 個崗位的說明、共同事項、開放時間。要改崗位內容改這裡 |
| `config.js` | 填入 Apps Script 網址。空白時為「示範模式」 |
| `GRG2026賽事籌備會議_v14.pdf` | 「賽事籌備細項」按鈕開的檔案 |
| `apps-script/Code.gs` | 後台程式，貼到 Apps Script |
| `staff-template.csv` | 名單範本（暱稱、電話），**不要上傳到 GitHub** |

## 部署後台（約 10 分鐘，用你的 Google 帳號）

1. 新增一份 Google 試算表，命名「GRG2026 工作人員認領」。
2. 選單「擴充功能 → Apps Script」，把 `apps-script/Code.gs` 全部貼上，存檔。
3. 上方函式選 `setup`，按「執行」，依畫面授權。試算表會出現 4 個分頁：名單、認領、填寫狀態、紀錄。
4. 在「名單」分頁貼上 20 位工作人員的暱稱和電話。
5. 右上「部署 → 新增部署作業 → 類型：網頁應用程式」
   - 執行身分：**我**
   - 誰可以存取：**所有人**
6. 複製「網頁應用程式網址」（/exec 結尾），貼到 `config.js` 的 `API_URL`。

之後改了 `Code.gs`，要用「管理部署作業 → 編輯 → 新版本」重新部署，網址不變。

## 後台怎麼看

- **填寫狀態**：每個人「已填 / 未填」，認領後自動更新。
- **認領**：20 個崗位各是誰。你也可以直接在這裡手動改（例如指派沒填的人）。
- **紀錄**：每次送出的結果，包含電話打錯。

## 規則（寫在 Code.gs 開頭，可改）

- 開放時間：2026-10-09 00:00（台灣時間），由後台判斷，改瀏覽器時間沒用。
- 一崗一人、先送先得；同一組暱稱＋電話可以改選或取消。
- 同一暱稱電話錯 5 次，暫停 15 分鐘。

## 本機預覽

直接用瀏覽器打開 `index.html`（示範模式）。網址後面加 `?open=1` 可以預覽開放後的畫面，示範暱稱：示範-小明 0912345678。
